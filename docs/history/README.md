# Historical reports

Point-in-time documents from earlier phases of this project. They record what
was true when they were written and are kept for context, **not** as current
guidance. Several describe the WikiDot scraping approach that Open5e replaced,
and the API behaviour they describe has since changed.

For current behaviour see [`../api-filters.md`](../api-filters.md), the
[README](../../README.md) and the ADRs in [`../adr/`](../adr/).

`API-FILTERS-2025.md` is the v1-era filter reference that
`../api-filters.md` replaced in 2026.
